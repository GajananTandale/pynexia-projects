# Monthly Rent & Expense Calculator

A command-line Python application that calculates and splits monthly living expenses—including base rent, electricity usage, groceries, and utilities—among roommates.

## Features
* **Detailed Cost Breakdown:** Computes electricity costs dynamically based on units consumed and rate per unit.
* **Input Validation:** Handles invalid text inputs, negative numbers, and zero-division errors gracefully.
* **Modular Design:** Separates input handling, calculation logic, and display formatting into clean functions.

## Requirements
* Python 3.x (uses only built-in standard features)

## How to Run
1. Navigate to the project folder:
   ```bash
   cd rent-calculator
   ```
2. Run the script:
   ```bash
   python rent_calculator.py
   ```
